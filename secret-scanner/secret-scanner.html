Bot Quét Bảo Vệ Code

Dán code (hoặc chọn file) vào đây trước khi đăng lên GitHub. Bot sẽ tìm những chỗ giống API key, mật khẩu, token bị lỡ viết thẳng trong code và chỉ đúng dòng cho Anh sửa.

Cam kết của bot này: quét 100% ngay trong trình duyệt trên máy Anh. Code Anh dán vào không được gửi đi bất cứ đâu — tắt mạng mở file vẫn quét được. Kết quả cũng tự che mờ key, không hiển thị nguyên key ra màn hình.

Bot bắt được: key Google/Gemini, key OpenAI, token GitHub, AWS access key, khóa riêng tư (private key), token Slack, và các dòng gán mật khẩu/API key viết thẳng trong code.
Bot không bắt được mọi thứ: key bị chia nhỏ, mã hoá, hay giấu trong ảnh đều qua mặt được nó. Quét sạch ở đây là tín hiệu tốt, không phải giấy chứng nhận an toàn tuyệt đối.
Nếu bot báo trúng key thật đã từng đăng lên mạng: việc đầu tiên không phải sửa code mà là vào trang của hãng thu hồi (revoke) key đó và tạo key mới — vì key đã lộ thì sửa code cũng không cứu được nữa.
